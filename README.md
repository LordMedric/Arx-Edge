# Arx-Edge Next-Generation Firewall

**Arx-Edge** (Medric Networks LLC) is an enterprise Next-Generation Firewall (NGFW), Unified Threat Management (UTM), and Secure Access Service Edge (SASE) appliance platform integrated with **Arx Cloud**.

## Core Capabilities
- Stateful Layer-4 / Layer-7 Firewall, Application Visibility & Control (App-ID), and Intrusion Prevention (IPS)
- Encrypted Global Edge Mesh & Zero-Trust Private Access
- Inline Data Loss Prevention (DLP), Exact Data Match (EDM), and Web & Email Threat Protection
- Hardware-Bound Sealed Appliance Runtime & Hardened Operating System
